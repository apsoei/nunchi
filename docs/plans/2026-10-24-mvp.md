# hanyeong-auto MVP 구현 계획

> 실행: 한 세션에서 직접 구현(native). 체크박스로 진행 표시.

**Goal:** 치는 도중 영어를 알아채 바로 전환하는 macOS 두벌식 한영 자동전환 입력기 첫 버전.

**Architecture:** 판단 로직은 전부 `HanyeongCore` 라이브러리(AppKit 의존 없음, 단위 테스트 대상)에 둔다. `HanyeongAuto` 실행 파일은 InputMethodKit 이벤트를 `KeyEvent` 로 바꿔 `KeyRouter` 에 넘기고, 돌려받은 `Effect` 목록을 클라이언트에 적용만 한다. 앱 번들은 SwiftPM 빌드 결과를 스크립트로 조립한다(Xcode 프로젝트 없음).

**Tech Stack:** Swift 6, SwiftPM, Swift Testing, InputMethodKit, Carbon(`IsSecureEventInputEnabled`).

**Spec:** 계획 Artifact https://claude.ai/artifact/T3csV4VebnUYqCaJ9VNDpP (로컬 사본 `../계획.html`)

## Global Constraints

- 네트워크 통신·자동 업데이트·손쉬운 사용 권한·전역 키 감시(CGEventTap) 금지.
- hannyeong 소스 미참조(클린룸). libhangul 미사용(조합기 직접 작성).
- 보안 입력 중에는 조합하지 않고 키를 그대로 앱에 넘긴다. 입력 소스를 바꾸지 않는다.
- 도중 전환 안전 규칙: 2타 이상, 같은 자모 반복(ㅋㅋ·ㅠㅠ)·초성 줄임말은 한글 유지, 한 번 영어로 바뀐 단어는 단어 끝까지 영어.
- Esc: 일반 앱에서는 미리보기 있을 때만 한↔영 뒤집기. 터미널·IDE 앱에서는 현재 모양대로 확정 + Esc 전달. 오른쪽 ⌘ 단독 탭은 어디서나 뒤집기.
- 회사 코드·데이터·사내 정보 미포함.
